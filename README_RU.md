# HT2 AutoSave 1.1.1

AutoSave использует штатное сохранение игры после выбранных событий и во время активной игры. Это ASI-плагин для *Hard Truck 2: King of the Road* («Дальнобойщики 2»).

## Возможности

- Сохранение после получения груза, успешной сдачи, победы в кольцевой гонке с наградой, покупки машины и найма водителя.
- Настраиваемый интервал активной игры; по умолчанию — 10 минут.
- По умолчанию хранятся три слота автосохранения: `autosave_1` — самый новый. Остальные ручные слоты не сдвигаются.
- Отложенная запись во время паузы, в меню и без фокуса игры; несколько событий объединяются в один запрос.
- Создание `plugins/HT2_AutoSave.ini`, если файла ещё нет; существующий INI не перезаписывается.
- Сообщения пейджера на русском, английском, французском, немецком и испанском.

## Настройки

INI использует секцию `[AutoSave]` и создаётся при первом входе в игровой мир. Файл читается один раз за игровой процесс; после изменения настроек перезапустите игру.

| Ключ | По умолчанию | Назначение |
| --- | --- | --- |
| `Enabled` | `true` | Включить мод |
| `OnCargoPickup` | `true` | Сохранять после получения груза |
| `OnCargoDelivery` | `true` | Сохранять после успешной сдачи груза |
| `OnRaceVictory` | `true` | Сохранять после победы в кольцевой гонке с наградой |
| `IntervalEnabled` | `true` | Включить таймер активной игры |
| `IntervalMinutes` | `10` | Интервал активной игры, 1–1440 минут |
| `MaxAutoSaves` | `3` | Количество слотов автосохранения, 1–99 |
| `ShowNotification` | `true` | Показывать сообщения пейджера |
| `OnVehiclePurchase` | `true` | Сохранять после успешной покупки машины |
| `OnDriverHire` | `true` | Сохранять после успешного найма водителя |

Логические значения: `true`/`false`, `yes`/`no`, `on`/`off`, `1`/`0`. Отсутствующие ключи получают встроенные значения по умолчанию; некорректное значение заменяется значением по умолчанию только для этого ключа. Мод создаёт INI, только если его нет, и не переписывает существующие байты, комментарии и дополнительные ключи. При ошибке чтения, создания или записи используются значения по умолчанию, а причина указывается в файле статуса. При переходе со старого пакета, который устанавливал INI как управляемый Workshop-файл, заранее сохраните настройки отдельно: синхронизатор может продолжать учитывать этот файл.

## Поддерживаемые версии игры

- `KOTR81`: русская версия игры 8.1, сверенная с указанным ниже эталонным SHA-256.
- `KOTR13`: международная *King of the Road* версии 1.3, сверенная с указанным ниже эталонным SHA-256. Известные английский, французский, немецкий и испанский EXE используют профиль только при совпадении SHA-256 с эталоном.
- Modified Game Core 8.2.

Совпадение номера версии само по себе не подтверждает совместимость. Сборка GOG отдельно не проверялась; совместимость с GOG не заявляется, пока EXE не проходит проверки мода и не протестирован.

Версия 1.1.1 устраняет конфликт сигнатур с **HT2 AI Trailers 1.3.6**. На релиз-кандидате проверены сохранение после взятия груза и загрузка на KOTR81, KOTR13 и ModifiedCore82. Другие изменения защищённого участка сохранения по-прежнему вызывают SignatureConflict.

## Установка и удаление

Требуются Windows, поддерживаемый 32-битный EXE игры и совместимый ASI Loader. Перед первым использованием закройте игру и сделайте резервную копию профиля `.pl1`. Скопируйте `plugins/HT2_AutoSave.asi` из ZIP в папку `plugins` игры. При обновлении с экспериментальной версии удалите `HT2_AutoSave_Experimental.asi`; одновременно устанавливайте только один ASI AutoSave.

Для удаления закройте игру и удалите `plugins/HT2_AutoSave.asi`. Мод не удаляет `HT2_AutoSave.ini` и слоты автосохранения: сохраните или удалите их самостоятельно.

## Сохранения, ограничения и диагностика

`autosave_1` — самый новый слот, далее `autosave_2` и т. д. Порядок сохраняется после перезапуска. Сдвигаются только слоты с именами `autosave_N`; другие ручные сохранения не затрагиваются. Пользовательские записи в слотах автосохранения не защищены от ротации. Формат сохранений не меняется; все слоты профиля находятся в одном файле `.pl1`, поэтому ошибка записи может повредить весь профиль.

Сдвиг слотов не атомарен. Ошибка может оставить неполную цепочку, после чего автоматические попытки отключаются до перезапуска игры. Возврат штатной функции сохранения и сообщение пейджера не доказывают, что данные записаны на диск. Перед первым использованием сделайте резервную копию. После старой кольцевой схемы 0.1.2 правильный порядок восстановится после достаточного количества новых автосохранений.

После входа в игровой мир проверьте `HT2_AutoSave_Status.ini`. `Result=Ready` и `Version=1.1.1` означают, что инициализация завершена. `IniStatus=Created` или `Existing` при `IniError=00000000` означает нормальную работу с настройками. При `ReadFailed`, `CreateFailed` или `WriteFailed` используются значения по умолчанию. `SignatureConflict` или `PatchFailed` отключают мод. `RotationFailed` останавливает следующие попытки до перезапуска. Для неподдерживаемого EXE файл статуса может не создаться.

## Зависимости во время игры и совместимость

Нужны игра и ASI Loader. Во время запуска AutoSave не зависит от Tractor Swap, Fleet Upgrade или других модов. Используются штатная функция сохранения и Win32 API; определение языка через Steam необязательно и имеет запасной вариант.

## Сборка из исходников

Нужны Python 3.10+ и Windows. Зависимости сборки и тестов закреплены в `requirements.txt` и `requirements-test.txt`:

```powershell
python -m pip install -r requirements-test.txt
$env:HT2_BUILD_INPUTS = 'C:\путь\вне\репозитория\к\локальным\файлам\игры'
python build.py --release
$env:HT2_TEST_RELEASE = '1'
python -m unittest discover -s tests -t . -p 'test_*.py' -v
python package_release.py
```

`HT2_BUILD_INPUTS` должен указывать на каталог вне репозитория со следующими файлами:

| Файл | Ожидаемый SHA-256 | Для чего нужен |
| --- | --- | --- |
| `KOTR81.exe` | `31fbd1dbbe7706183f09a3688482791255db2bfb557c02675374b96796ce2ebd` | KOTR81 / 8.1 |
| `ModifiedCore82.exe` | `b57eb1e34dd00c6c5270ca42ada931039d9baed488dee5bb33f46ffa2a6097d6` | Modified Game Core 8.2 |
| `KOTR13.exe` | `0df6861c9e67c2a2ae373cff8d765ae41cc76079d8f84b9340e609263edd983f` | Эталон KOTR13 / 1.3 |
| `ht2ach.dll` | Из локальной установки игры | Только один регрессионный тест Steam-достижений |

Игровые файлы в проект не включены. Сборка AutoSave самостоятельна и не требует исходников Tractor Swap. Результаты сборки находятся только в игнорируемом каталоге `build-output/`. Инструкция для ZIP находится в [`packaging/README.txt`](packaging/README.txt) и включается в установочный архив.
